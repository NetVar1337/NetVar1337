# Executive GitHub Profile README Design

## Purpose

Turn NetVar1337’s profile README into a longer, professional executive security profile that leads with the Co-Owner role at Decepticon.red while presenting credible security research and tooling.

## Audience and outcome

Security practitioners, prospective collaborators, and technical evaluators should understand NetVar’s leadership role, Decepticon.red’s controlled operating model, relevant research focus, and selected public work in one screenful of scannable Markdown.

## Structure

1. **Identity** — compact linked Decepticon logo, `NetVar` heading, and the exact title `Co-Owner, Decepticon.red`.
2. **Leadership summary** — a short paragraph describing governed autonomous red-team operations, operator control, and evidence-driven work.
3. **Decepticon.red** — a two-column GitHub table: product / open-source project on one row and a concise description on the other.
4. **Operating principles** — four compact entries: runtime-enforced scope and Rules of Engagement; OPPLAN objectives, blockers, pivots, evidence, and next actions; ATT&CK/Skillogy-grounded specialist agents; observable execution under operator control.
5. **Research and tooling** — two-column table of selected work: `decepticon-ghidra-mcp`, `omniwire`, and `unleash`, with descriptions taken from their public repositories.
6. **Connect** — plain-text Discord username `netvar` plus links to the Decepticon.red website and Decepticon GitHub organization/project.

## Visual rules

- Keep the Decepticon logo linked to `https://decepticon.red/`, use `https://decepticon.red/logo.png`, and retain descriptive alt text.
- Use semantic headings, horizontal rules, concise paragraphs, bullets, and GitHub Markdown tables only.
- Keep the logo at a compact `width="220"`; do not use animated assets, video, badges, dynamic stats, external stat cards, counters, or ASCII-art framing.
- Keep all text readable without images or custom CSS.

## Claim boundaries

- Product claims are limited to the official Decepticon.red site: runtime controls, OPPLAN execution tracking, specialist-agent context, and operator control.
- Research/tool descriptions are limited to the linked public repository descriptions.
- Do not include benchmark figures, pricing, beta dates, unverified customer claims, or unsupported personal credentials.

## Verification

The completed README must render on GitHub with the logo loading, `Co-Owner, Decepticon.red` visible, the required Decepticon sections and selected-project links visible, and every destination HTTPS URL reachable.
